# Sistema de Gestión de Alumnos

Proyecto web desarrollado con **React** y **Vite** para la gestión básica de alumnos, incluyendo listado, creación, filtro interactivo y estilos visuales.

## Requisitos Previos

Asegúrate de tener instalado en tu equipo:
- [Node.js](https://nodejs.org/) (versión 18 o superior)
- `npm` (incluido con Node.js)

## Instalación y Configuración

1. **Clonar el repositorio:**
   ```bash
   git clone <https://github.com/Mildredgrave/react-segundoParcial.git>
   cd sistema-alumnos

2. En la terminal correr los siguientes comandos: 
para instalar dependecias: 
npm install

para correr proyecto: 
npm run dev - Inicia el servidor de desarrollo.
npm run build - Compila la aplicación para producción.
npm run preview - Sirve la build de producción localmente para pruebas.
